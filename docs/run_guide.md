\# YottaFlex AI — Execution Guide



\## 1. Prerequisites



\- Windows 10 or Windows 11

\- Python installed

\- PowerShell

\- Project dependencies: pandas, NumPy, and pytest

\- Power BI Desktop for dashboard visualization



Run commands from the project root directory.



\## 2. Activate the Virtual Environment



```powershell

.\\.venv\\Scripts\\Activate.ps1

```



If dependencies are missing, install them:



```powershell

python -m pip install pandas numpy pytest

```



\## 3. Generate the Raw Data



The project contains scripts for generating plant, machine, meter, energy, production, tariff, weather, and anomaly-test datasets.



Run the relevant generator scripts from the project root, using the filenames present in `src`.



\*\*Important:\*\* Some scripts depend on files generated by earlier scripts. Inspect each script before rerunning generators, because doing so may overwrite existing datasets.



\## 4. Run the Analysis Pipeline



The following scripts implement the main analysis stages:



1\. `src/production\_energy\_analysis.py` — associates production batches with energy readings.

2\. `src/tariff\_cost\_analysis.py` — calculates electricity costs by tariff.

3\. `src/validate\_tariff\_cost.py` — validates tariff cost results.

4\. `src/machine\_efficiency.py` — analyzes machine energy intensity.

5\. `src/batch\_anomaly\_detection.py` — flags unusual batch energy intensity.

6\. `src/daily\_anomaly\_detection.py` — flags unusual daily energy consumption.

7\. `src/machine\_priority\_report.py` — prioritizes machines for investigation.

8\. `src/machine\_tariff\_costs.py` — summarizes tariff-based electricity costs by machine.

9\. `src/integrate\_tariff\_costs.py` — combines priority metrics with tariff costs.

10\. `src/integrated\_report.py` — generates the integrated report.

11\. `src/executive\_summary.py` — generates the executive summary.



Run each script with Python from the project root. Confirm its input files exist before executing it.



\## 5. Validate the Results



Run the automated tests:



```powershell

python -m pytest .\\tests -v
```

\## 7. Power BI Dashboard



Open the saved `YottaFlex\_AI\_Dashboard.pbix` file in Power BI Desktop.



Verify that the report uses the latest intended CSV outputs. Refresh the data and inspect the visuals before presenting the dashboard.



\## 8. Execution Notes



\- Run commands from the project root unless a script specifies otherwise.

\- Do not rerun generators blindly; they may overwrite data.

\- Confirm the input files and column names before running dependent scripts.

\- Re-run relevant validators after changes.

\- The project currently uses synthetic data and synthetic tariff assumptions.
